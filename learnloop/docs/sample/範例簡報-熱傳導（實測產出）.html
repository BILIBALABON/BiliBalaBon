傅立葉定律與熱傳導基本規律

傅立葉定律 q = -k(dT/dx) 是熱傳導的基本規律

  • 熱通量 q：單位時間內通過單位面積的熱量，單位 W/m²
  • 熱傳導係數 k：材料導熱能力，單位 W/(m·K)，k 越大導熱性越強
  • 溫度梯度 dT/dx：沿傳導方向單位距離的溫度變化率，驅動熱流流動
  • 負號表示熱流方向與溫度梯度相反：熱總是從高溫流向低溫
講解備註溫度梯度是驅動熱流的微觀動力。在分子層面，高溫區分子運動激烈，低溫區相對靜止。高溫區的活躍分子與低溫區分子碰撞時把能量轉移過去，溫度梯度越陡峭這種轉移就越劇烈，熱流也越大。負號確保計算結果符合物理現實，反映熱力學第二定律。

熱傳導係數：材料導熱性能的量化指標

不同材料的熱傳導係數相差高達 10000 倍，決定了導熱還是隔熱

  • 金屬（導熱性強）：銅 400、銀 429、鋁 237 W/(m·K)
  • 合金與陶瓷（中等）：不鏽鋼 16、陶瓷 1.2、玻璃 1.1 W/(m·K)
  • 氣體（隔熱性強）：空氣 0.026 W/(m·K)，比金屬小 10000 倍
  • 選材原則：需散熱用金屬、需隔熱用多孔材料（內含靜止空氣）
講解備註金屬高導熱性源自大量自由電子的快速移動；氣體導熱差是分子密度低、碰撞機會少。實際工程應用：CPU散熱片選銅或鋁；保溫牆選玻璃棉或聚氨酯泡沫。關鍵是選對材料，才能有效散熱或隔熱。

熱阻與複合結構傳熱計算

多層複合結構的熱阻串聯：類比電路分析解決複雜傳熱問題

  • 熱阻公式：R = L/(k·A)，厚度越大、k 越小，則熱阻越大
  • 串聯原理：R₍總₎ = R₁ + R₂ + R₃ + ...，類比電路電阻串聯 R₍總₎ = R₍電₎1 + R₍電₎2 + ...
  • 瓶頸效應：玻璃棉層（R₂=2.5）佔總熱阻 90%，是最關鍵的隔熱部分
講解備註例題中外層水泥 R₁ = 0.02/(1.4×1) = 0.0143 K/W ≈ 0.01 K/W（四捨五入至小數點第 2 位）、玻璃棉 R₂ = 2.5 K/W、內層磚 R₃ = 0.20/(0.8×1) = 0.25 K/W，總計 R₍總₎ ≈ 2.76 K/W。玻璃棉因導熱係數最小（0.04），即使厚度不是最大，熱阻仍然最大，主導隔熱性能。工程師利用這個原理設計保溫系統：找出最低 k 值或最厚的層，就找到了熱流最容易被阻擋的地方。熱流量 Q = ΔT/R，對應歐姆定律 I = V/R。

熱傳導的工程應用與保溫設計

保溫材料設計與高壓應用中的相變過程：隔熱策略與工作溫度的考量

  • 設計原理：玻璃棉、聚氨酯泡沫包含大量靜止空氣（k ≈ 0.026 W/(m·K)）
  • 孔隙精心設計為微米級，防止空氣形成對流循環，靜止空氣才能隔熱
  • 隔熱性能倍增：玻璃棉（k ≈ 0.04）比實心玻璃（k ≈ 1.1）好 27 倍
  • 高壓系統應用：高壓蒸汽鍋爐利用相變過程隨壓力變化調整工作溫度，水的沸點從常壓 100°C 升到 1 MPa 時的 179.9°C，提高能源效率
講解備註在高壓系統（如高壓蒸汽鍋爐、高壓容器）的隔熱設計中，物質的相變性質隨壓力變化會影響系統的允許工作溫度範圍。沸點升高决定了隔熱層必須承受的最高溫度，進而影響隔熱材料的選擇和厚度設計。設計時必須查閱蒸汽表確定特定壓力下的飽和溫度，才能選出適合的隔熱材料和計算所需熱阻。

熱阻與複合結構傳熱計算

想一想：多層牆體中哪一層對隔熱效果最關鍵？

某複合牆體由三層組成：外層水泥（厚 2cm、k=1.4 W/m·K）、中層玻璃棉（厚 10cm、k=0.04 W/m·K）、內層磚（厚 20cm、k=0.8 W/m·K）。計算各層熱阻：R₁ ≈ 0.01、R₂ = 2.5、R₃ = 0.25 K/W（R₁ 四捨五入至小數點第 2 位）。在相同溫度差下，哪一層對整體隔熱性能的影響最大？

答案是 B。多層結構的總熱阻是各層之和，影響最大的是 R 值最大的層。中層玻璃棉 R=2.5 K/W 佔總熱阻 2.764 K/W 的 90% 以上，遠大於水泥層（0.01）和磚層（0.25）。這就是為什麼保溫設計中保溫層是最關鍵的部分。A 選項只考慮位置忽視了熱阻的概念；C 選項看厚度而忽視了導熱係數的決定性影響——玻璃棉 k 最小，即使厚度與磚層相近，熱阻也大得多。

熱傳導期中考核心四點

  • 傅立葉定律 q = -k(dT/dx)：負號表示熱流與溫度梯度反向，是熱傳導的數學基礎
  • 熱傳導係數 k 決定材料導熱能力，不同材料相差 10000 倍，決定選材原則
  • 熱阻 R = L/(k·A) 和串聯計算 R₍總₎ = ΣR：工程設計的計算工具，類比電路分析
  • 工程應用：利用空氣低 k 值設計保溫材料，利用熱阻串聯優化多層結構，實現散熱或隔熱目標
